Choose where Writingway stores automatic project backups.

GitHub Gist Setup

  1. Go to GitHub Settings → Developer settings → Personal access tokens
  2. Click "Generate new token (classic)"
  3. Give it a name such as "Writingway Backup"
  4. Select the gist permission only
  5. Paste the token below

Local Versioning

Each backup is written to the project-backups/ folder inside Writingway. This keeps timestamped restore points on this machine without requiring any cloud login.

This provider is listed for planning, but its sign-in and sync flow is not implemented yet. Use GitHub Gist or Local Versioning for working backups today.
